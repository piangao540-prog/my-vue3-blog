项目亮点：

- **RAG 向量问答**：直接调大模型回答会脱离文章内容（幻觉）、全量塞入又超上下文——设计"切块 + **BGE embedding** 向量化 + 余弦检索 top-k"管线，**8 篇文章**让 AI 基于真实内容回答
- **Function Calling**：模型无法直接检索、手工拼参数易格式漂移——接入 search_articles 工具，实现"判断 → 执行 → 回答"**两轮对话**

- **多会话与渲染**：会话无法切换、刷新丢失——封装 **useChatSessions** 管理会话 + localStorage 持久化；未闭合代码块容错
- **工程化与安全**：TypeScript 类型约束、**JWT 登录鉴权**（bcrypt 加密 + 中间件校验 + 拦截器携带 token）、参数化查询防 SQL 注入、开发 Vite Proxy + 生产 CORS 解决跨域
