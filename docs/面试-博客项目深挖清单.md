# 博客项目面试深挖清单

## 0. 开场白(30 秒版本)

模板:这是一个前后端分离的全栈博客,Vue3 + TS 做前端,Express + MySQL 做后端,部署在 Vercel + TiDB。核心亮点是 AI 能力——RAG 向量问答、Function Calling 让模型能调用搜索文章的工具、SSE 流式输出实现打字机效果;业务上有文章、评论、收藏、后台管理;最近还做了图片压缩上传 + 懒加载的完整管线。

练习标准:30 秒讲完"做了什么、怎么做的、亮点是什么",不卡壳。

## 1. 项目整体 ★必问

1. 介绍一下你的博客项目
