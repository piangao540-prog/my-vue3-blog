# 博客项目亮点（简历替换版，含 RAG）

**项目简介**（保持不变）

独立完成个人博客系统的设计与开发，实现文章管理、用户认证、评论互动、收藏管理及后台管理等功能，采用前后端分离架构。

**项目亮点**（整段替换）

- **RAG 向量问答**：文章切块 + BGE embedding 向量化 + 余弦相似度检索 top-k，让 AI 基于博客真实内容回答，避免幻觉
- **Function Calling**：接入 search_articles 工具，实现"判断是否检索 → 执行检索 → 携带结果回答"的两轮对话
- **SSE 流式输出**：基于 Fetch + ReadableStream 封装流式请求模块，处理块边界截断（buffer 缓存未完整行）与 AbortController 中断，实现打字机效果
- **多会话与渲染**：useChatSessions 实现多会话切换与 localStorage 持久化；Markdown 流式渲染支持未闭合代码块容错
- **全栈架构设计**：前端基于 Vue3 + TypeScript 开发，后端使用 Express + MySQL，实现前后端分离，完成从需求分析、数据库设计到部署上线的完整开发流程
- **工程化与安全优化**：采用 TypeScript 进行类型约束，使用参数化查询防止 SQL 注入，通过 Vite Proxy 解决跨域问题
- **项目部署**：前端基于 Vercel 实现自动化部署，后端同步部署至 Vercel，结合 TiDB Cloud 提供 MySQL 兼容数据库服务

**两处小修**：

- 技术栈行 `Echarts/ Express` → `ECharts / Express`
- 教育背景补学校全名
